# Security reporting

Report suspected vulnerabilities privately to
[adhikaridayamoy@gmail.com](mailto:adhikaridayamoy@gmail.com).
Include the affected version, impact and reproduction steps. Do not include
passwords, private signing keys or unnecessary personal data.

Do not publish vulnerability details in issues or pull requests before the
maintainer has had an opportunity to investigate. This project does not promise
a fixed response time or a vulnerability bounty.
